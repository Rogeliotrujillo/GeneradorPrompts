# 🤖 Generador de Prompts (C#)

Aplicación de escritorio desarrollada en **C# (Windows Forms)** que ayuda a los usuarios a crear prompts estructurados y efectivos para Inteligencias Artificiales.

## ✨ Características
* **Estructura en 4 pasos:** Instrucción, Contexto, Formato y Restricciones.
* **Generación en tiempo real** con formato enriquecido (títulos en negrita).
* **Contador de palabras** automático.
* **Integración directa:** Copia el prompt y abre ChatGPT o Gemini con un clic.

## 🚀 Cómo ejecutar
1. Clona el repositorio: `git clone https://github.com/Rogeliotrujillo/GeneradorPrompts.git`
2. Abre el archivo `.sln` en Visual Studio.
3. Presiona `F5` para ejecutar.
